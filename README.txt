Important:
A Progressive Web App must be served from HTTPS (or localhost). It will not install correctly when opened directly as a local file.

Simple hosting options:
1. Netlify Drop: drag the whole folder onto Netlify Drop.
2. GitHub Pages: upload the files to a repository and enable Pages.
3. Cloudflare Pages: upload or connect a repository.

After hosting:
- Open the HTTPS address in Chrome on Android.
- Tap the Install app button in the page, or Chrome menu > Install app / Add to Home screen.
